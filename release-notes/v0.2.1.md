**GitCraft 0.2.1** is a small patch release on top of 0.2.0.

## Changed

- **Squash and fixup are one command.** *Edit commit → Squash into parent…* now asks how to treat the commit message: combine both messages, or keep the parent's and discard the other. This replaces the separate *Squash into parent* entry in the top level of the commit menu and the *Fixup into parent* entry.

## Downloads

| System | File |
| --- | --- |
| Windows | `.msi` installer |
| macOS, Apple silicon and Intel | `.dmg` disk image (one for each chip) |
| Linux | `.deb` package and a portable `.AppImage` |

The installers aren't code-signed yet. Windows SmartScreen and macOS Gatekeeper will warn on first launch; on macOS, right-click the app and choose Open.

See the [README](https://github.com/Jorgen-VikingGod/GitCraft/blob/v0.2.1/README.md) for the full feature list, keyboard shortcuts and build instructions.
