**GitCraft 0.6.0** makes GitCraft much quicker on Windows. A refresh starts far fewer git processes, the window does less work per frame, and the checked-out branch and commit now always stand out in the accent colour.

## Added

- **Troubleshooting switches.** `GITCRAFT_TRACE=1` logs every git call GitCraft makes and how long it took; any other value is taken as a file to write the log to. `GITCRAFT_GIT_JOBS` sets how many git calls may run at once. `GITCRAFT_RENDERER=glow` draws with OpenGL instead of the default renderer.

## Changed

- **Faster on Windows.** A refresh now starts 7 git processes instead of 20. GitCraft starts Git for Windows' real `git.exe` directly rather than through its launcher, which halves the cost of each call. It also skips the queries that can't find anything, such as stashes, submodules or LFS in a repository that has none. On Windows at most 6 quick git calls run at once, so a burst doesn't swamp the disk and the virus scanner.
- **Less reloading.** Staging, unstaging or editing a file reloads only the status. The history is read again only when a branch, tag or stash moved. Changes to files git ignores no longer start a refresh, and refreshes asked for while one is running are merged into one.
- **A lighter window.** Settings are saved in the background, and only when they changed. Progress messages redraw at most 30 times a second. Long lists of changed files and branches draw only the rows in view.
- **Direct3D 12 on Windows.** GitCraft now draws with Direct3D 12 instead of Vulkan. `WGPU_BACKEND` still chooses another backend.
- **The checked-out branch and commit keep the accent colour.** Picking another branch, tag or commit shows it in grey, so the one you're on always stands out.

## Fixed

- **Flicker on Intel graphics.** On Windows the whole window flickered for a few seconds when it redrew quickly, such as when the mouse moved fast over it.
- **Changes to tracked files that an ignore rule matches** are noticed again. Edits to `.git/info/exclude` take effect without reopening the repository.
- **Fetching more history of a shallow clone** now shows the older commits right away.
- **Opening a repository** no longer keeps an outdated history if a branch moved while it opened.
- **Submodules** are listed even while `.gitmodules` is deleted but not yet committed.
- **Partial clones** are recognized whatever way their `promisor` setting is written (`yes`, `on`, `1`).
- **A git program of your own on Windows**, chosen in *Settings › Git*, is used as it is, even when it sits in Git for Windows' folder.
- **Selecting files upwards** with **Shift+↑** in *Local changes* keeps the row you moved to in view.
- **A failed settings save** is tried again with the next change, or when GitCraft quits.
- **Closing and reopening a tab** on the same repository no longer lets the old tab's loading land in the new one.

## Downloads

| System | File |
| --- | --- |
| Windows | `.msi` installer |
| macOS, Apple silicon and Intel | `.dmg` disk image (one for each chip) |
| Linux | `.deb` package and a portable `.AppImage`, or the apt repository (package `git-craft`) |

The installers aren't code-signed yet. Windows SmartScreen and macOS Gatekeeper will warn on first launch. On macOS 15 (Sequoia) and later, open GitCraft once, then click **Open Anyway** in *System Settings › Privacy & Security*; on older macOS, right-click the app and choose Open.
