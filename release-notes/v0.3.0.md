**GitCraft 0.3.0** adds support for git worktrees.

## Added

- **Worktrees in the sidebar.** A new *Worktrees* section sits next to *Stashes* and lists every working tree of the repository with its branch (or the commit when detached). Locked and missing worktrees are marked, and the one you are looking at is highlighted.
- **Worktree actions.** Double-click a worktree to open it in a new tab. Right-click for *Open in new tab*, *Copy path*, *Remove…* and, for stale entries, *Prune*. Add one with the **+** button or *Add worktree…* in the repository menu; give a new branch name, or leave it empty to check out detached.
- **Worktree info in titles.** A tab for a linked worktree is tagged *worktree*, and the main checkout shows *N worktrees* when others exist. The window title includes the same information.

## Downloads

| System | File |
| --- | --- |
| Windows | `.msi` installer |
| macOS, Apple silicon and Intel | `.dmg` disk image (one for each chip) |
| Linux | `.deb` package and a portable `.AppImage` |

The installers aren't code-signed yet. Windows SmartScreen and macOS Gatekeeper will warn on first launch; on macOS, right-click the app and choose Open.
