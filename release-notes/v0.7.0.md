**GitCraft 0.7.0** moves GitCraft onto the craft-ui runtime of the Craft apps, so its window, menus and keys work like theirs. The menu bar and the context menus now share one look, and the commit graph gets a column of its own that scrolls sideways when a repository has many branches side by side.

## Added

- **A scrolling graph column.** The commit graph now stays in its own column, however many lanes it has. More lanes than fit scroll sideways with **Shift + wheel**, a trackpad or the scroll bar under the graph, with a soft shadow at the side where more lanes are out of view. Drag the column's edge in the header to make it narrower; switching to a tab opens it as wide as it can be, while the description keeps room for its text.
- **A coloured block before each commit message**, in the colour of the commit's dot and lane, so you can see at a glance which message belongs to which dot.
- **Tooltips for text that doesn't fit.** A commit message cut off at the end of its column, or a branch, tag or remote name cut off in the sidebar, shows in full under the pointer.
- **Keys of the Craft apps.** **Ctrl/⌘ + Q** quits, and **F10** or **Alt** goes to the menu bar (Alt + a letter opens that menu).
- **A control server for scripts and tests.** Started with `GITCRAFT_CONTROL_PORT`, GitCraft lets scripts click, type, open dialogs, choose menu entries and save pictures of its window. It listens on `127.0.0.1` only and every connection must give its token first. `docs/automation/control.py` is a small client.

## Changed

- **Built on craft-ui.** GitCraft's window now runs the interface runtime of the other Craft apps, which takes care of keyboard focus, Escape, the menu bar keys, quitting and the interface scale.
- **One look for all menus.** The menu bar and the right-click menus are drawn the same way, in GitCraft's colours, with a soft highlight under the pointer. Entries that lose work, such as *Drop commit…*, show on a faint red row. In a group of choices, such as *View › Tabs*, only the chosen one has a dot.
- **The checked-out branch is bold** in the sidebar, as its commit is in the history.

## Fixed

- **Many parallel branches** no longer draw the graph's lines over the commit messages, authors and dates.
- **The checked-out branch's name** sometimes didn't look bold, depending on where it sat in the sidebar.

## Downloads

| System | File |
| --- | --- |
| Windows | `.msi` installer |
| macOS, Apple silicon and Intel | `.dmg` disk image (one for each chip) |
| Linux | `.deb` package and a portable `.AppImage`, or the apt repository (package `git-craft`) |

The installers aren't code-signed yet. Windows SmartScreen and macOS Gatekeeper will warn on first launch. On macOS 15 (Sequoia) and later, open GitCraft once, then click **Open Anyway** in *System Settings › Privacy & Security*; on older macOS, right-click the app and choose Open.
