**GitCraft 0.5.0** brings undo and redo, a safety net for discarded changes, bisect, history filters, Git LFS, submodules and sparse checkout, git's own settings, editable keyboard shortcuts, clearer conflicts, and a reworked interactive rebase editor.

## Added

- **Undo and redo.** *Edit › Undo* and *Redo* (**Ctrl+Z**, **Ctrl+Shift+Z** or **Ctrl+Y**; **⌘** on macOS) for commits, amends, resets, checkouts, branches, tags, merges, rebases, cherry-picks, reverts, pulls and discards.
- **Discarded changes are kept.** Discarding files, hunks or lines keeps a backup for 30 days. *Repository › Recover discarded changes* puts them back, without overwriting what changed since.
- **Commit options.** Sign-off, skip hooks, co-authors (`Co-authored-by`) and push after committing. **Ctrl+Shift+Enter** stages everything and commits. Amending a commit that is already pushed asks first.
- **Stash and revert parts of a file.** Stash just a hunk or some lines, stash only the untracked files, rename a stash, or take a single file back from it. In a commit's diff, *Revert hunk* (or selected lines) takes that part back out of the working tree.
- **Several commits at once.** Pick commits with **Ctrl+click** or **Shift+click**, then cherry-pick, squash, drop or replay them onto HEAD.
- **More history editing.** Make a `fixup!` commit of the staged changes for any commit, cherry-pick a merge commit relative to a chosen parent, and move a commit up or down from its menu.
- **Bisect.** Start from a broken commit's menu, name one that still worked, then mark each commit as good, bad or skip until the first bad one is found.
- **Compare more.** A commit with the working directory, and two versions of a series of commits (*Repository › Compare commit ranges*). The merge and rebase dialogs say beforehand which files would conflict (git 2.38+). The reflog can show every branch's, not only HEAD's.
- **Filter the history** by author, file or folder, or changed text (*View › Filter history…*); a file's menu shows the history of its folder.
- **Hide or solo branches** in the graph with the eye and filter icons on a branch's row, or from its menu. Remembered for each repository.
- **History options.** Stashes appear in the graph above the commit they were made on, the graph can be ordered by date, columns can be chosen and resized, and a Changes column shows lines added and removed.
- **Signatures.** A commit's details say whether its signature is good. Blame can skip the commits in `.git-blame-ignore-revs`.
- **Fetch and push.** Fetch every few minutes in the background (Settings › Repository), fetch more history for shallow and partial clones, give a remote a push URL of its own, and delete a tag on one chosen remote. When a push or pull fails, GitCraft offers the way out: pull or push with lease, set the upstream, add a remote.
- **Checkout.** Bring uncommitted changes along as they are. Checking out a remote branch fast-forwards its local branch when that is behind.
- **Clean up branches** (*Repository › Clean up branches…*): merged, squash- or rebase-merged, and those whose upstream is gone, reviewed in a list; optionally their remote branches too.
- **Clone and init options.** Clone one branch, only recent history, without submodules, blobless or only some folders. Start a repository with a first branch name, a `.gitignore` for a language, a README and a first commit. `gitcraft://clone?url=` links open the clone dialog.
- **Repository tools.** Sparse checkout, add, update and remove submodules, lock and unlock worktrees and create them from a commit or branch, and a maintenance dialog (gc, commit-graph, fetch with prune).
- **Git LFS** (*Repository › Git LFS*, when git-lfs is installed): set it up, store files by pattern (optionally lockable), download the LFS files, and lock and unlock files with a list of every lock on the server. A checkout that needs LFS is refused while git-lfs is missing.
- **Patches.** Save a series of commits or the local changes as a patch. Copy a file's text from a commit, and mark a resolved file as conflicted again.
- **git's own settings** (*Settings › Git*), everywhere or for one repository: name and email, commit and tag signing, line endings, first branch name, rerere and the hooks folder. Choose which git program GitCraft runs, and forget the saved passwords of a repository's remotes.
- **Editable keyboard shortcuts** (*Settings › Keyboard shortcuts*): click a key and press the new one, add a second key, go back to the default or clear it. Your keys are saved and shown in the menus.
- **About window** under *Help › About GitCraft*, with the version and the git in use.

## Changed

- **Conflicts say who is on each side.** The banner reads "Merging feature into main" or "Rebasing feature onto main", and both sides are named ("main · this branch", "feature · being merged"; in a rebase, which side is your commit).
- **A page for each conflicted file.** It says what each side did, offers *Use this side*, *Resolve in GitCraft* and your merge tool, and previews the conflicting parts.
- **Commit box during an operation.** A merge's commit box holds git's prepared message, which you can edit; *Continue* commits with it. A rebase, cherry-pick or revert shows what continuing commits instead.
- **Interactive rebase editor.** Each commit's action is a dropdown, rows show the date, dropped commits are crossed out, and the highlighted commit's author, message and files are shown below the list.
- **Settings window.** Wider, with a page per topic.
- **Branch and commit menus** are grouped into submenus, without entries listed twice.
- **Look.** Buttons that can't be used are drawn faded instead of left out, dialogs close with an accent button, and dropdown entries sit closer together.
- **The branch you have checked out can't be hidden** from the graph; git always shows its commits.

## Fixed

- **Code in the conflict resolver** keeps its indentation.
- **Hunk headers.** Their text no longer shows through the gaps between the hunk buttons.
- **Discarding a new file** deleted it for good; it is now kept with the other discarded changes.
