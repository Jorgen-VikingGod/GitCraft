**GitCraft 0.4.1** corrects the apt install instructions.

## Fixed

- **apt package name.** The README and the apt repository's page said `sudo apt install gitcraft`, which apt can't find: the package is called `git-craft`. Both now give the right command. If you already added the repository, install with:

  ```bash
  sudo apt update && sudo apt install git-craft
  ```

  The program is still started as `gitcraft`. Nothing else has changed since 0.4.0.

## Downloads

| System | File |
| --- | --- |
| Windows | `.msi` installer |
| macOS, Apple silicon and Intel | `.dmg` disk image (one for each chip) |
| Linux | `.deb` package and a portable `.AppImage`, or the apt repository (package `git-craft`) |

The installers aren't code-signed yet. Windows SmartScreen and macOS Gatekeeper will warn on first launch; on macOS, right-click the app and choose Open.

See the [README](https://github.com/Jorgen-VikingGod/GitCraft/blob/v0.4.1/README.md) for the full feature list, keyboard shortcuts and build instructions.
