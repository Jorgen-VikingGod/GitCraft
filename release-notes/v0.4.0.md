**GitCraft 0.4.0** speaks German, French and Spanish, opens files in your own diff and merge tools, asks before checking out over local changes, and has a new look.

## Added

- **External diff and merge tools.** *Settings › External tools* lists the graphical tools git can start on your system, such as KDiff3, Beyond Compare or Meld, plus any you set up yourself in git. Pick one diff tool and one merge tool, and GitCraft remembers them. Right-click a changed file, a file of a commit or a file of two compared commits and choose *Open in …*; for a conflicted file choose *Resolve in …* or use the button on the conflict screen. GitCraft keeps working while the tool is open.
- **Checkout with local changes.** Switching branches with uncommitted changes now asks what to do: *Stash and reapply*, *Commit first* or *Discard changes*. Discarded changes are kept in a stash, so nothing is lost, and if the changes clash with the new branch the stash stays as well.
- **Languages.** The interface is available in English, German, French and Spanish. It follows the system language, or choose one under *View › Language*.
- **Menu bar.** All commands are in *File*, *Repository*, *View* and *Help* menus, with their keyboard shortcuts shown next to them.
- **Tabs.** Drag tabs into a new order. When they don't fit, arrows scroll the tab bar, and *View › Tabs* lists every open repository. The open tabs, their order and the front tab come back when you start GitCraft again.
- **Full screen.** Press **F11** (or *View › Full screen*) for full screen without a title bar.
- **Select all files.** **Ctrl+A** (**⌘A** on macOS) selects every file of a list in Local Changes.
- **Window and title bar.** GitCraft remembers the window's size and place. Choose between GitCraft's own title bar and the system's under *View › Use system title bar*.
- **apt repository.** On Debian and Ubuntu, install GitCraft with apt and get updates the same way. See the README for the three commands.

## Changed

- **New look.** Neutral grey panels, sections drawn as cards, and an azure accent in both themes. The light theme has more contrast.
- **Clearer buttons.** Main actions and staging use the accent colour, unstaging is orange, and actions that discard or delete (Discard, Delete, Abort, Drop) are red.
- **Lists.** Scroll bars appear when you hover, a shadow shows that a list goes on past its edge, and rows have a small gap between them.
- **File dialogs** no longer block the window.
- **Settings** are now stored in `config.toml`. Settings from earlier versions are carried over once.

## Fixed

- **Syntax colours** in diffs now follow a switch between light and dark.
- **History scroll bar.** It was hard to grab, because the window's resize edge lay over it.
